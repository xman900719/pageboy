# 产品定位与范围

**书童（ShuTong）**：个人非商业北京初三中考冲刺学习 Web/PWA。首批学科语文、数学、英语、物理。历史中考真题 → 可信答题与学校试卷证据 → 目标画像和现实画像比较 → 可解释训练计划 → 未见题独立验证。

当前为 private single-owner foundation。四科共享基础数据合同，数学端到端验证先行，随后组合学科差异。不能承诺未校准预测成绩；不能将学校月考和中考等值；英语听说、物理实验及其余计分科目尚未完整纳入，不得宣称总分510的预测。

重要产品不变量见 [数据模型](../design/data-model.md)；真实验收见 [验收索引](../quality/acceptance.md)。

## 当前明确非目标

商业平台、未授权真题公开传播、全网爬虫、自动客观化全部开放题、复杂 Agent/微服务/多节点双活、预先实现 BKT/IRT、完整 PWA 离线练习、正式分数预测。
