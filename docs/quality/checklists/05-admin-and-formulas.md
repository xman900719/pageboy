## 一、 测试环境与测试操作

- **访问路径**：进入 `/admin.html` 综合管理工作台（覆盖顶部 3 个一级栏目：**「题库与体检」**、**「学校考试」**、**「知识点审核」**）
- **核验设备**：用于前端测试的 iPad 模拟机环境（触控模式，支持竖屏 `810×1080` 与横屏 `1080×810`）
- **重点检验**：
  1. 三大管理端模块的分阶段子页签（`StageTabStrip`：题库与体检 4 阶段 / 学校考试 4 阶段 / 知识点审核 3 阶段）清晰导航，且每步视口严格单卡聚焦（`max-width: 980px`），绝不平铺/堆叠多张卡片；
  2. **方式 A 严防跳步门禁**：前置条件未满足的步骤胶囊显示 `🔒`（`aria-disabled="true"`），点击时阻止切入并展示顶部橙色明确引导横幅（`不可跳步至……`）；
  3. 题源与建档的「台账列表 / 新建模式」同卡切换、自动步进与跨卡 CTA 收尾（含「原卷与草稿校对」对「报告导入/全科同步」生成草稿的旁路直通第 3 步校对台、「知识点审核」第 2 步「按课标生成依据草稿并进入第 3 步」）；
  4. 附件原生「选择文件」交互、`v-model` 表单双向绑定与提交规范指引；
  5. 全站知识点标签中文本地化、KaTeX 公式安全排版与奇数 `$` 纯文本安全回退、听力音频控件触控。

## 二、 核验步骤与判定标准

| 步骤编号 | 测试操作 | 预期交互现象 | 合格标准 (Pass) | 否决标准 (Fail) |
| :---: | :--- | :--- | :--- | :--- |
| **5.1** | 打开「题库与体检」→ 第一阶段「题源与来源审核」，点击未选或未满前置的锁步胶囊（如未传附件时点击「附件解析与录入」第 2 步「逐题人工录入工作台」）；再用「＋ 登记新题源」新建并推进 `1 → 2 → 3` | 核查单卡展示与防跳步锁定 | 每次仅居中显示 1 张卡片；未满足前置的步骤显示 `🔒`，点击触发明确阻断横幅而不跳过步骤；切换模式可正常登记题源并推进到概览与来源人工审核 | 同屏平铺多个业务卡片；未满足前置即可跳步进入空白或报错卡片 |
| **5.2** | 在「题库与体检」第二阶段「附件解析与录入」第 1 步点击「选择原始附件」选取本地测试文件，测试「清空」并审阅提交规范气泡；解析后点击「逐题录入并确认导入」进入第 2 步 | 调用原生文件选择器并按 `1 → 2` 步流转 | 选择文件后正确显示文件名与大小且可清空；上传附件自动将已审核题源复位为未审核；解析后解锁第 2 步逐题录入台 | 点击无反应、无法选择文件，或无法进入第 2 步录入台 |
| **5.3** | 打开「学校考试」检查四阶段分区：「第一阶段 · 前置立锚（总分台账与建档）」→「第二阶段 · 材料入库（按需选路：报告导入与核对 / 全科校考同步 / 原卷与草稿校对）」→「第三阶段 · 明细查漏」→「第四阶段 · 诊断终点（错误分析与复盘）」；测试未建档/未传原卷且无草稿时点击锁步步骤，以及「报告导入」生成的草稿能否旁路直达「原卷与草稿校对」第 3 步 | 核查阶段分流、单卡步进与旁路解锁 | 各阶段子卡严格 1 步 1 卡；未选场次或未解析前锁定步骤带 `🔒` 提示；「报告导入」或「全科同步」已有待核对草稿时无需先上传单科 PDF 即可解锁第 3 步校对台；无失分明细时「错误分析」如实提示不足并给出补录入口 | 四阶段混淆、多卡并排挤压，或报告生成草稿后校对台仍被锁死 |
| **5.4** | 打开「知识点审核」查看紧凑顶部工具栏 + 三阶段导航（「第一阶段 · 同步与逐条审定」/「第二阶段 · 全局依据参照（只读）」/「第三阶段 · 强门禁发布」）；未同步入库前尝试点击第 3 步，随后按第 1→2→3 步点击「按课标生成依据草稿并进入第 3 步」并在版本发布页测试快照视图 | 核查顶部瘦身与三步审核发布联动 | 顶部摘要不再占独立大卡，横竖屏均单卡专注；未同步入库时第 3 步带 `🔒` 拦截；同步后可顺畅由第 2 步带草稿直入第 3 步；有待审节点时门禁阻断发布并明确给出返回入口 | 顶部占屏过高、仍三列挤在一起，或带草稿未跳转第 3 步 |
| **5.5** | 审阅全站知识点标签、含 `$…$` 与 `$$…$$` 的公式题干（如分式 $\frac{a}{b}$、根号 $\sqrt{x}$）、含奇数个 `$`（如 `买书花了 $15 元`）及听力音频控件 | 核查标签中文化、KaTeX 公式与音频播放 | 知识点标签均由配置文件渲染为中文；数学公式正常矢量排版且无 `$` 裸露；奇数 `$` 安全回退不报错；音频播放器触控响应流畅 | 裸露英文内部编码（`math.gap` 等）、LaTeX 报错红字或页面横向溢出 |
| **5.6** | 在 iPad 模拟机竖屏（`810×1080`）与横屏（`1080×810`）间切换并操作阶段条、步骤胶囊及表单输入 | 核查平板响应式适配与零横向溢出 | 四阶段与三阶段导航条、步骤胶囊在不同宽高下自动优雅折行/切换为 2 列或单列，卡片居中舒适，页面零横向滚动条（`scrollWidth <= innerWidth`） | 出现横向溢出、按钮截断重叠或触控区过小难以点击 |

## 三、 测试人判定（选项点选生效）

> 测试人核验时点选对应选项，每个选项均明确绑定了具体的测试内容与验收合格标准：

- [x] **判定 1：通过（Pass）**  
  - **具体核验内容**：
    1. 依次操作管理端「题库与体检」（4 阶段）、「学校考试」（4 阶段含三路分流）、「知识点审核」（3 阶段+紧凑顶部栏）；
    2. 验证每一步仅展示单张居中卡片，确认锁步胶囊（`🔒`）点击后阻断跳步并给出明确引导；
    3. 验证「建档 → 材料分流 / 报告旁路解锁校对台 → 明细查漏 → 错误分析」及「选点 → 查课标带草稿入第 3 步 → 审核 → 发布快照」连贯性；
    4. 验证附件选择、中文化标签、KaTeX 公式、奇数 `$` 回退、音频控件及 iPad 横竖屏无横向溢出。
  - **验收合格标准**：
    1. 全部 3 个管理端一级栏目彻底消除多卡平铺，单卡聚焦、主次明确；
    2. 前置未满的锁步状态不可越级进入，提示具体明确；完成每步操作后自动平滑解锁或跳转下一步；
    3. iPad 模拟机横竖屏均零横向溢出、触控点击准确无报错。

- [ ] **判定 2：未通过（Fail）**  
  - **适用情形**：核心流程可走通，但仍存在个别步骤文案歧义、排版错位、窄屏轻微挤压或跳步引导不够明确。

- [ ] **判定 3：暂时中断核验，先修理Bug（Halt & Fix）**  
  - **阻断验收判定标准**：
    1. 仍出现多张业务卡片并排/堆叠，或某阶段卡片彻底无法打开/一直锁死无法解锁；
    2. 点击未满足前置的步骤仍可跳步入空白页/报错；
    3. 表单提交失败、附件选择无响应、KaTeX 报错崩溃或 iPad 出现横向溢出。  
    *出现上述任一阻断现象，必须立即中断测试，交由 Agent 先行修复。*

- [ ] **判定 4：前置阻塞未启动（Blocked）**
