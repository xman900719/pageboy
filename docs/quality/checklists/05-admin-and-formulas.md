## 一、 测试环境与测试操作

- **访问路径**：进入「题库审核台」视图（点击顶部 Tab「审核台」）
- **核验设备**：用于前端测试的 iPad 模拟机环境（触控模式，支持横竖屏）
- **重点检验**：
  1. Vue 3 `v-model` 表单双向绑定流畅度与题源录入；
  2. 审核台附件本地文件浏览触发器、已选文件高亮卡片及「📄 试卷与教学资料提交规范指引」；
  3. 全站知识点标签中文本地化（由 `knowledge-labels.json` 配置文件驱动，严禁组件内硬编码）；
  4. KaTeX 专业公式排版（矢量数学字体）与奇数 `$` 纯文本安全回退（ST-013）；
  5. 听力音频播放器控件触控与进度条。

---

## 二、 核验步骤与判定标准

| 步骤编号 | 测试操作 | 预期交互现象 | 合格标准 (Pass) | 否决标准 (Fail) |
| :---: | :--- | :--- | :--- | :--- |
| **5.1** | 在审核台顶部表单输入题源标题与科目，点击「新建题源」 | 登记试卷/教辅来源 | 题源列表中新增一项，表单字段由 `v-model` 正常绑定并清空恢复默认 | 表单字段无法录入或列表未刷新 |
| **5.2** | 展开附件上传区，审阅试卷规范面板，点击「📂 浏览本地文件…」并选取本地测试文件（如试卷 PDF 或图片） | 调用原生文件选择器并高亮选定文件 | 弹出文件选择窗口；选定后高亮展示「已就绪文件」卡片（含文件名、格式化大小及清空按钮）；规范面板明确指引月考试卷与听力音频提交要求 | 点击无反应、无法选择文件或缺少月考试卷提交指引 |
| **5.3** | 审阅题库题源列表、草稿详情及各卡片中的知识点标签 | 核查知识点本地化呈现 | 所有知识点标签均呈现为友好中文（如「差距考点（薄弱短板）」、「达标考点（对照）」、「听力专项（模拟）」），由配置文件驱动 | 界面出现生硬裸露的代号（如单独显示 `math.gap`、`math.ok`、`math.listen` 且无中文） |
| **5.4** | 观察含有数学公式的题干渲染（如分式 $\frac{a}{b}$、根号 $\sqrt{x}$） | 渲染带 `$…$` 与 `$$…$$` 题干 | 公式按专业数学排版（矢量字体、清晰分式与希腊字母）渲染，**绝不显示原生裸露 `$` 符号** | 遗留原生 LaTeX 字符串未解析 |
| **5.5** | 观察奇数个 `$` 符号的非规范输入（例如题干文本包含 `买书花了 $15 元`） | 触发安全回退策略 | 整串原样作为普通安全文本显示，无 KaTeX 语法红字报错，无 XSS 隐患 | 页面崩溃或出现 HTML 乱码 |
| **5.6** | 在支持听力的题源中，触控点击听力音频播放器（AudioPlayer）控件 | 测试音频播放交互 | 播放器能够正常响应触控播放、暂停，进度条拖动平滑 | 播放器无响应或报错 |

## 三、 测试人判定（选项点选生效）

> 测试人核验时点选对应选项，每个选项均明确绑定了具体的测试内容与验收合格标准：

- [x] **判定 1：通过（Pass）**  
  - **具体核验内容**：
    1. 在审核台顶部录入表单输入题源标题，切换科目点击「新建题源」；
    2. 展开附件上传区域，查阅「📄 试卷与教学资料提交规范指引」面板，并触控点击「📂 浏览本地文件…」选择任意本地文件，查看选定后的卡片并测试「清空重选」；
    3. 审阅题源列表、草稿详情、首页池健康度与练习页题目卡片中的知识点标签；
    4. 检验分式与根号等公式渲染排版，确认无裸露 LaTeX 原生标记；
    5. 检验奇数 `$` 符号文本（如商品单价或货币描述）的安全回退渲染表现；
    6. 触控测试英语听力音频组件的播放、暂停与进度控制。
  - **验收合格标准**：
    1. 表单录入顺畅响应，新建题源即时加入列表，双向绑定清空正常；
    2. 附件上传面板明确注明月考试卷整卷扫描、听力原音频上传与录入要求；点击「📂 浏览本地文件…」按钮可流畅调出系统文件选择器，选定后文件名称与文件大小清晰可见，支持一键清空；
    3. 全站知识点标签均由 `apps/web/src/config/knowledge-labels.json` 集中配置驱动，界面清晰展示规范中文释义（如「差距考点（薄弱短板）」、「听力专项（模拟）」等），严禁未配置硬编码与生硬代号裸露；
    4. 数学公式按 KaTeX 矢量字体完美排版，零代码裸露；
    5. 奇数 `$` 等非规范公式输入平滑安全降级为普通文本呈现，控制台绝无 KaTeX 红色 ParseError 抛错，无 XSS 风险；
    6. 听力音频播放器触控灵敏可用。
    *以上 6 条具体标准全部达成，全站前端重构与安全加固正式达到生产级交付标准！*
