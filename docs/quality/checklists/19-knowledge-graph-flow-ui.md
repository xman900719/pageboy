## 二、 逐项核验清单

- [x] **19.1 · 领域分组与清晰 DAG 有向拓扑展示**：进入「知识点展示 → 🗺️ 关系图谱」，切换数学 / 语文 / 英语 / 物理四科，确认各领域以虚线容器分组展示、内部叶子考点按自上而下先修流向排列、中文名称完整无截断、节点卡片无重叠，且无内部英文编码（如 `math_cand.`、`num_alg`）泄露。
- [x] **19.2 · 脉络溯源高亮与「仅看选中脉络」子图切换**：点击画布中任意知识节点（如「一元二次方程及其解法与判别式」或「有理数及其运算」），确认上游前置链（橙框）与下游进阶链（青框）高亮、激活边显示中文关系标签、无关节点温和淡化，且右侧/下方「选中知识点详情」同步联动；点击工具栏「🕸️ 仅看选中脉络」仅保留关联因果路径图，再次点击可恢复完整图谱。
- [x] **19.3 · 跨领域桥梁快捷跳转、领域筛选与清单/双游戏兼容**：点击画布底部「跨领域先修桥梁」胶囊可定位对应节点；点击「数与代数」等领域筛选标签、「仅高亮未掌握」、「🎯 定位选中节点」、「⛶ 自适应全览」及 `－ / ＋` 缩放按钮均响应顺畅；切换「📋 切换清单视图」、「⚗️ 知识合成工坊」、「🧭 迷雾科技树探险」及详情栏「针对此知识点开始练习」功能正常。
- [x] **19.4 · iPad 竖横屏触控流畅性与零横向溢出**：在 iPad 竖屏（`810×1080`）与横屏（`1080×810`）下核验页面整体零横向溢出；单指在画布外/上下滑动页面顺畅不被画布劫持；画布内拖拽平移、捏合/按钮缩放流畅。
