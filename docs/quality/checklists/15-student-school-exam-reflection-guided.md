## 二、 逐项核验清单

- [x] **15.1 · 标题统一为「校考复盘」**：确认学生端顶部导航、工作台主标题以及管理端「逐题明细核对台 / 人工补录」中的引导提示均已统一为 **「校考复盘」**，不再出现「校考错题复盘」或「错题复盘」；练习页「近期错题回顾」与管理端「错题诊断」保持不变。
- [x] **15.2 · 复盘首页移除「日常练习错题回顾」**：在「校考复盘」页依次切换数学、语文、英语、物理、道法，确认下方不再出现任何学科的「日常练习错题回顾」区块；切换回「练习」页确认「近期错题回顾」仍正常可用。
- [x] **15.3 · 三步引导与句式起头**：进入任意一场待复盘校考，确认每道失分题按「① 回到考场 → ② 找到那一步 → ③ 给下次的提醒」三步引导；选完第 1 步考场情境后自动进入第 2 步并优先推荐相关错因；选中错因后点击句式起头可插入输入框并自由改写；步骤间可前后切换。
- [x] **15.4 · 去抵触反馈与底线校验**：确认界面已移除字数计数与“防敷衍”说教文字；仅点击句式起头不补全内容或只写“粗心/下次注意”提交时，页面以温和书童追问口吻拦截；补全具体卡点与“如果…我就先…”提醒后可成功提交，并以「给下次的提醒卡」样式展示。
- [x] **15.5 · 去惩罚化沟通与 iPad 双屏排版**：在管理端对已完成复盘的题目点击「退回重写」并填写原因，切回学生端确认状态显示为 **「家长想和你再聊聊这题」** 与 **「家长留言：…」**；在 iPad 竖屏（810×1080）与横屏（1080×810）下均无横向溢出与按钮遮挡。
