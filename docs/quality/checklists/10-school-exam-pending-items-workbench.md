## 二、 逐项核验清单

- [x] **10.1 · 术语去歧义（「待核对明细 / 逐题明细核对台」）**：检查校考工作台顶栏徽标（「待核明细: N 题」）、阶段 Tab（「原卷与明细核对」）、第 2 步（「2. 自动提取待核对明细」）、第 3 步（「3. 逐题明细核对台」）及报告/同步中心跳转文案，确认不再混用语义不明的「草稿」表述，且题库模块「题目草稿」保持原有语义。
- [x] **10.2 · 题号自然升序排列**：打开含 ≥ 10 道待核对明细的数学/多学科真实校考场次，确认列表严格按 `第 1 题 → 第 2 题 → … → 第 10 题 → …` 自然数字升序排列，不再出现 `1, 10, 11, …, 2` 的字典序错乱。
- [x] **10.3 · 方案三布局（三栏纵向堆叠卡）无重叠/截断**：在桌面/iPad 横屏（`1080 × 810`）下检查每行 3 卡布局，在 iPad 竖屏（`810 × 1080`）下检查自动降级为每行 2 卡布局；确认卡片内各字段全宽逐行堆叠、无文字换行压住下拉框现象、页面无横向滚动条（`scrollWidth <= innerWidth`）。
- [x] **10.4 · 所有分数只读不可编辑**：检查列表内任意题目卡片，确认「实得分」与「满分」均以只读分值横幅展示（`实得 X / 满分 Y 分`），不存在可修改分数的数字输入框。
- [x] **10.5 · 满分题作答正确，不显示错因与复盘备注**：找到「实得分 = 满分」的题目，确认顶部横幅呈绿色 `✓ 作答正确`、仅显示「所属知识点」输入框与「✓ 实得分与满分一致（作答正确），无需填写错因分类与复盘备注」提示，**不渲染**「错因分类」与「错题复盘备注」输入框；仅失分题（`实得分 < 满分`）才显示错因与复盘备注。
- [x] **10.6 · 消除 `'unmapped'` 脏预填 & 快捷交互提效**：
  - 未映射考点的题目输入框初始为空（显示中文提示），点开可直接下拉选择中文课标知识点，不再显示被截断的 `'unmapped'`；
  - 顶部只读分值汇总条准确显示「小题汇总（已核 + 待核）」及与卷面总分的差额/吻合状态；
  - 状态筛选胶囊（`全部 / 待补考点 / 失分题 / 满分正确 / 已就绪`）、单题「同上题」复用按钮与「先确认已就绪项 / 批量确认本页待核明细」工作正常（注意：若对开发库真实题点击确认后不可逆，建议仅在确认核对无误的真实题目上测试确认，或验证前先确认清楚该场次归属）。
