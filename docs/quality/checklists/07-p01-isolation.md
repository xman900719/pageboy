## 三、 同源架构剩余风险说明 (F03 Residual Risk Note)

当前管理端页面（`admin.html`）与学生端页面（`index.html`）部署在同一 Web Origin 下。

- **已实施防护**：服务端通过 `SHUTONG_ADMIN_TOKEN` 与 `SHUTONG_STUDENT_TOKEN` 双凭据在 API 层做严格角色鉴权，学生凭据与管理凭据互斥拦截；管理端凭据已彻底移除 `localStorage` 持久化，仅当前页面响应式内存持有，页面关闭/刷新即销毁。
- **剩余风险说明**：由于管理端与学生端共享浏览器 Origin，在同源上下文下，若恶意脚本注入页面（XSS），可能读取同源内存或发起同源请求。该风险属于架构演进议题（未来可按 D08 规划引入独立管理域名或外围身份隔离），目前未证实发生任何凭据越权。本阶段遵守最小修改原则，不擅自改动生产域名或引入复杂认证框架。
