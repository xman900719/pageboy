## 二、 逐项核验清单

- [x] **17.1 · 双轨自由切换与结合原题开场**：在学生端任意失分题 Tab 中，确认可在「三步引导卡片」与「书童陪你想」之间自由切换；点开已确认题干的错题「书童陪你想」，确认书童结合原题与考点提出简短、温和的第 1 个小问题，绝不直接报答案。
- [x] **17.2 · 无已确认题干诚实降级**：切换到一道尚未确认题干的失分题并点开「书童陪你想」，确认书童如实说明暂时看不到原卷文字、请学生描述题意与第一步想法，绝不编造题干条件。
- [x] **17.3 · 持久化恢复与整理草稿回填闭环**：与书童对话 1 轮时确认底部提示“聊满 2 轮后可整理”；发送第 2 轮真实思考后刷新页面再切回该题「书童陪你想」，确认历史对话完整恢复且未重复生成开场白；点击 **「把刚才聊明白的整理成提醒卡草稿 →」**，确认自动跳回三步卡片并填入错因/卡点/提醒草稿且**不会自动提交**；自由修改后点击「收好提醒卡 ✓」成功保存。
- [x] **17.4 · 管理端只读回溯与 iPad 双屏零溢出**：切回管理端「学校考试 → 第四阶段 → 4. 失分题干与学生复盘」，确认该题出现 **「查看书童对话过程（N 条）」**，默认折叠、点击可只读展开学生与书童的完整对话；在 iPad 竖屏（810×1080）与横屏（1080×810）下学生端与管理端均无横向溢出。
