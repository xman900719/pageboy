## 一、 测试环境与测试操作

- **访问路径**：`http://127.0.0.1:5173/admin.html` → 顶部栏目 **「学校考试」** → **「全科校考同步」**（及 **「总分台账与建档」**、**「原卷与草稿校对」**）
- **核验设备**：宿主机 iPadOS 模拟机（`uv run python scripts/run_dev_env.py sim` 竖屏 `810×1080` 与 `sim-landscape` 横屏 `1080×810`）
- **重点检验**：
  1. 第 1 步（扫描收件箱）与第 2 步（卷头五字段识别、候选匹配、原卷入档）保持原有能力；
  2. 第 3 步 **「k12100 报告同步」** 无需先匹配试卷即可进入；点击 **「从 k12100 下载总分报告并同步」** 后，宿主机可见浏览器按真实账号读取首页场次并从「总分 → 报告打印 → 下载PDF」下载未同步场次报告；
  3. 下载报告后自动按 k12100 首页日期 + 报告/首页的学年度、年级、考试类型、学科新建或更新补全后端考试档案，所有新建/更新总分及逐题草稿保持待人工核对状态；
  4. 已人工锁定总分或身份冲突仅提示不覆盖；再次点击同步时自动跳过已同步场次；
  5. iPad 横竖屏零横向溢出、按钮触控可达。

## 二、 核验步骤与判定标准

| 步骤编号 | 测试操作 | 预期交互现象 | 合格标准 (Pass) | 否决标准 (Fail) |
| :---: | :--- | :--- | :--- | :--- |
| **8.1** | 进入「全科校考同步」，检查第 1、2 步并直接点击第 3 步「k12100 报告同步」 | 第 1、2 步试卷列表与匹配控件保留；第 3 步无需前置匹配可直接打开 | 看到「从 k12100 下载总分报告并同步」主按钮与「显示宿主机浏览器窗口」选项；凭据显示脱敏账号且不泄露明文密码 | 第 3 步被锁死无法点击，或原有试卷录入功能缺失 |
| **8.2** | 勾选「显示宿主机浏览器窗口」，点击「从 k12100 下载总分报告并同步」 | 弹出宿主机 Chromium 窗口，自动复用会话或账号登录，进入「总分 → 报告打印 → 下载PDF」下载未同步场次（最多 3 场） | 任务状态经排队/下载/解析平滑推进至「已完成」，展示首页场次与各学科结果列表 | 报错未捕获、无限转圈、跳过平台验证码未停止或泄露学生真实姓名/密码 |
| **8.3** | 核对结果列表、各科总分独立确认及全科/单科排名与最高分展示 | 新建、更新、补全、锁分冲突、缺日期/歧义标签分明；仅核对其中 1 科总分后刷新，仅该科变为「已核对」，其余各科保持「待核对」；第 3 步与第 4 步均展示总分及各科班排/年排、班级最高分/年级最高分 | 考试时间与 k12100 首页一致；年级/类型/学科一致；核对 1 科总分**绝不连带锁定其他科**；总分与各科班排/年排及班/年最高分完整可见；`ocr_draft` 保持「待核对」 | 核对 1 科导致其他科一并变成已核对、缺失班级/年级最高分或排名、或日期/身份错位 |
| **8.4** | 先点「本地核对并补全排名/最高分」，检查预检条变为「已全部完整同步」后再点「从 k12100 下载总分报告并同步」（含中断后再同步并刷新，以及第 1 步/报告中心重扫收件箱） | 本地补全无需重下即把历史同场报告合并去重、清理跨科/同哈希冗余答题卡并补齐排名/最高分；同步前预检如实反映完整性；全部完整时再点同步直接跳过，**不进入报告下载页**；每场考试在列表与库内只存在 1 条记录；跨学科点「打开档案」正常跳转 | `sync_readiness.all_complete=true` 时再次同步零重复下载；同场仅 1 条持久化报告且无重复/跨科错配答题卡（如数学仅保留本学科页）；重扫收件箱不新建重复报告；前期同步内容持续显示 | 同场考试保存多份重复记录/多份答题卡、已完整同步仍重复下载报告、或中断/刷新后列表消失 |
| **8.5** | 回到第 1/2 步，对本地试卷点击「重新执行自动匹配」并检查「报告导入与核对」Tab | 本地试卷可匹配到第 3 步新建的考试档案；「报告导入与核对」Tab 仍正常工作 | 第 2 步精确匹配成功；「报告导入与核对」Tab 可查看已下载登记的报告册与答题卡切图 | 新建档案无法被试卷匹配，或「报告导入与核对」Tab 异常 |
| **8.6** | 在 iPad 模拟机竖屏（`810×1080`）与横屏（`1080×810`）下检查第 3 步结果表与按钮 | 列表、标签、操作按钮布局清晰 | 横竖屏均无横向溢出（`scrollWidth <= innerWidth`），所有按钮可读可触控 | 横向滚动条出现、文字截断严重或按钮重叠 |
