# iPad 真机核对清单（ST-016）

> 本环境（开发机）无法驱动真实 iPad，以下检查须由 owner 在**自己的 iPad** 上执行。
> 每条都标注了"期望结果"；任何不符请原样回报（截图或文字），不要自行改动部署。
> 入口：Safari 打开 https://shutong.xmanspace.asia （Cloudflare Access 先要求登录，用 owner 邮箱）。

## A. 基础循环（首页 → 练习 → 诊断）

1. 登录 Access → 输入访问令牌 → 进入。
   期望：进入三视图（首页/练习/阶段诊断/审核台导航可见），无白屏、无控制台报错文案。
2. 首页查看「题库体检」卡片。
   期望：显示"已发布 N 题 / 未见题余量 M 题 / 已曝光 K 题"与各知识点行；数字与你在审核台发布的数量相符（当前生产库 math 已发布 5 题、未见 3 题，可作为基准核对）。
3. 练习：点"开始练习"→ 作答（单选直接点选项）→ 提交。
   期望：立即显示"本题得分 X / Y"与评分来源；换一题后题干确实变化。
4. 阶段诊断：点"领取未见题诊断"→ 独立作答 → 提交。
   期望：显示"符合独立验证条件（首次见题、独立完成），已计入阶段对比"，并出现"计划已刷新"区块。

## B. 公式渲染（ST-013）

5. 审核台 → 新建题源（虚构标题即可）→ 填来源人工审核（年份/链接/版权依据/适用性，勾选人工核查）→ 上传任意小附件或直接"逐题录入"。
6. 录入一条题干含 `$$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$`、选项含 `$a+b$` 的单选题 → 确认导入 → 人工审核通过 → 重新做来源人工审核 → 发布。
7. 练习里按该知识点取题。
   期望：公式以排版形式渲染（分式/根号/±，不是原始 `$…$` 文本）；长公式不撑破卡片（可横向滚动）；文本部分正常。

## C. PWA 与横竖屏（ST-010/ST-012 真机复核）

8. Safari 分享 → "添加到主屏幕" → 从主屏幕图标启动。
   期望：standalone 全屏启动（无 Safari 工具栏），图标为 PNG 主屏幕图标。
9. 竖屏/横屏各旋转一次；再试分屏（Slide Over / Split View）。
   期望：布局自适应，无横向溢出、无可点区域被裁切。
10. 退出 PWA（多任务界面划掉）→ 重新从图标启动。
    期望：若进入时勾选了"在本机记住令牌"则免输入直达；未勾选则需重新输入令牌（默认仅内存，这是红线行为）。
11. 飞行模式 → 在 PWA 内下拉刷新。
    期望：显示"无法连接服务器，请检查网络连接后重试。"之类的网络提示（不是白屏，也不是"无法连接本地服务（默认 :8000）"——那是修复前的错误文案）。

## D. 回报格式（便于归档为 ST-016 证据）

- 每步：通过 / 不通过 + 实际看到的内容（文字或截图）。
- iPad 型号与系统版本、Safari 版本。
- 若某步失败：发生时间、复现步骤、是否必现。
