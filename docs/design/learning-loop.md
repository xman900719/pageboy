# 双画像、差距分析、自适应训练与独立验证

## 六段业务闭环

目标（科目分数、考试基线、时间预算）→ 候选目标画像 → 练习/校卷/独立测评形成现实画像 → 差距/证据缺口 → 专项训练步骤 → 未见题独立评估 → 重新规划。

两类画像必须遵守统一评价口径；学校月考与北京中考并非当然等值。未经过考试蓝图和校准样本支撑，不得把目标分数反推成精确知识点阈值。候选目标要求应显式标记假设。

## 当前可执行启发式

`services/api/shutong/guidance.py` 是纯函数，输入独立、首曝、客观已评分且只有一个主考点的 Evidence；至少3道独立题后才给出观察比例。少于3题返回证据不足。按科目目标比例使用0.7/0.8/0.9三个**未校准的规划代理阈值**，主要用于演示规则决策，绝不是考试能力或预测分数。

如果题目早已曝光，只能作为复练，不能标记新题验证。复测还需检查题型、难度与评分可比性；当前骨架仅实现“是否曾曝光”的第一道门槛，**并未完成正式的独立效果推断**。

## 需要后续实现

- 学校试卷上传、逐题人工核对、评分点证据；多来源可信度等级。
- 目标画像基于已审核考试蓝图生成多候选路径、标明无法覆盖的听说和实验。
- 有真实题库覆盖支持的知识点、难度与前置依赖，预计投入成本与训练效益。
- 计划快照、可解释依据、重算版本和阶段级触发，避免每做一道题计划震荡。
- 限时条件与真正可比未见题复测，样本不足显示“无法判断”，并检验跨时间保持。
