# ADR-0001：选择模块化单体与组合复用

- 状态：Accepted for V1.6 foundation
- 背景：个人非商业项目、四学科、需要强一致的题目/答题/画像数据，尚无分布式流量或多团队部署需求。
- 决策：一个 FastAPI 进程、PostgreSQL 单库、领域逻辑分离；解析/OCR/AI 通过窄接口独立运行；前端 React Web/PWA。
- 备选：微服务、消息总线、Graph DB、通用 Agent 平台。
- 理由：KISS/YAGNI 与 DRY；共享领域事件事实但不共用权限与流程；必要时沿接口扩展。
- 后果：初期部署简单；需纪律性约束跨模块写入，重构前后必须跑行为测试。
